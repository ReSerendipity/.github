# ADR-0003：`enforce_admins=false`——个人账号直推的取舍

- 状态：Accepted
- 日期：2026-10-22
- 决策者：ReSerendipity（账号所有者）
- 相关：§2 分支规范

## 背景

`.github` 与多个项目仓的 `main` 已配置分支保护。GitHub 的分支保护有 `enforce_admins` 开关：开启后管理员也必须走 PR，不能直推。本账号是**个人账号**，所有者同时是唯一高频维护者；若开启，日常单行修复也要开 PR，且本机自动化（豆包 agent、脚本推送）会被平台拒绝。

## 决策

- 全部受保护仓保持 `enforce_admins=false`。
- 保护对**非管理员协作者**、force-push、分支删除、必需检查仍然生效。
- 所有者直推是**已声明的例外**，不视为绕过治理；补偿控制是 DCO、`pre-push` 钩子、本地预检脚本与周检审计。
- 将来若引入第二维护者或公开协作，再评估改为 `true`。

## 后果

- 优点：保留个人账号的迭代速度，不把每次修复都变成 PR 仪式。
- 代价：**保护不约束账号本人**；误推只能靠事后审计发现，不能靠平台拦截。
- 代价：`required_status_checks` 对本人也不阻断，红灯不阻止合并。

## 不采用

- `enforce_admins=true`：与个人账号单维护者模型冲突，会把所有紧急修复堵在平台侧。
